# Mon CV React - Portfolio Web

Application web développée avec React et Bootstrap permettant de présenter le portfolio fictif d’un développeur web nommé John Doe.

Le projet comprend :
- une interface responsive
- plusieurs pages de présentation
- un portfolio dynamique
- un formulaire de contact
- une navigation moderne avec React

# Installation

1. Clonez le projet sur votre machine locale.
```bash
git clone https://github.com/USERNAME/mon_cv_react.git
```

2. Installation des dépendances
```bash
npm install
```

3. Démarrer le serveur de développement
```bash
npm run dev
```

4. Lancer l'application localement
```bash
npm run serve
```
